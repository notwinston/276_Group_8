# Meeting 1: Introductions and Project Proposal

**Attendees:** Winston, Jimin, Habib, Ajay, Even

## Strengths

- **Winston:** AI and machine learning (PyTorch, TensorFlow, Hugging Face, recommendation systems), plus full-stack web development and cloud deployment.
- **Jimin:** Front-end web apps with HTML, CSS, and JavaScript, and Git and GitHub.
- **Habib:** Full-stack web apps with Java, Spring Boot, JavaScript, REST APIs, and databases, especially search and filtering features.
- **Ajay:** Full-stack web apps with Java, Spring Boot, REST APIs, and SQL, including authentication with Spring Security, team repositories, and Docker deployment.
- **Even:** Relational database design, SQL, JSON, and Java.

## Proposals

- **Jimin** proposed a browser-based SFU room finder that helps students locate classrooms and study spaces, with building and floor information and directions.
- **Habib** proposed saved rooms, study-space filters, detailed room pages, student feedback on noise and group suitability, and a way to report incorrect room information.
- **Winston** proposed bringing room information, saved locations, and feedback together in one interface, and expanding the project into degree planning, course recommendations, and AI workload analysis using the SFU Course Outlines API.
- **Ajay** proposed letting students rate and weigh in on study spaces, and analyzing foot traffic to show when spaces are usually busy.
- **Even** proposed syncing SFU course data into our own database on a schedule and keeping past terms so we can track when courses are offered.

The group agreed to combine these ideas into one application called Summit SFU.
